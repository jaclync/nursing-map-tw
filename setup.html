Nursing Map Taiwan - Setup Instructions

ℹ️ Quick Start: This project uses Apple MapKit JS to display nursing locations on an interactive map. Follow the steps below to set it up.

📋 What You Need

  • A free Apple Developer account
  • 5-10 minutes for initial setup
  • Node.js (optional, for token generation helper)

🚀 Setup Steps

Step 1: Create a Free Apple Developer Account

Visit developer.apple.com and sign up for a free account using your Apple ID.

Step 2: Create a Maps ID
  1. Go to Certificates, Identifiers & Profiles
  2. Click on "Identifiers" → "+" button
  3. Select "Maps IDs" and click "Continue"
  4. Enter a description and identifier (e.g., com.yourname.nursing-map-tw)
  5. Click "Continue" and then "Register"
Step 3: Create a Private Key
  1. Go to "Keys" section and click the "+" button
  2. Enter a key name (e.g., "MapKit JS Key")
  3. Check the "MapKit JS" checkbox
  4. Click "Continue" and then "Register"
  5. Download the private key file (.p8) - save it securely!
⚠️ Important: Keep your private key file (.p8) secure and never commit it to version control. The key can only be downloaded once!
Step 4: Generate a JWT Token

You have two options:

Option A: Use the provided script (Recommended)

# Install dependencies
npm install jsonwebtoken

# Edit generate-token.js with your details
# Then run:
node generate-token.js

Option B: Use online tools

Follow Apple's documentation: Creating and Using Tokens

Step 5: Configure Your Token
  1. Copy the generated JWT token
  2. Open map.js
  3. Replace YOUR_MAPKIT_JS_TOKEN_HERE with your token
  4. Save the file
Step 6: Run the Application
# Option 1: Using Node.js
npm start

# Option 2: Using Python
python3 -m http.server 8000

# Option 3: Using PHP
php -S localhost:8000

Then open your browser to http://localhost:8000

✅ Success! Your map should now display with the nursing location marker. Click on the marker to see detailed information.

📝 Adding More Locations

Edit the data.json file to add more nursing locations. Each location should include:

  • Name and address information
  • Geographic coordinates (latitude, longitude)
  • Optional: phone, opening hours, notes, etc.

❓ Troubleshooting

Issue: Map not loading
Solution: Check that your JWT token is valid and properly configured in map.js
Issue: "Please configure your Apple MapKit JS token" error
Solution: Make sure you've replaced the placeholder token in map.js
Issue: Markers not showing
Solution: Verify that your data.json has valid latitude and longitude values
